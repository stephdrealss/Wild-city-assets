# Wild City PH character models

The player character is a Mixamo character (ch03) converted to glTF: `player.glb` holds her skinned mesh with textures resized to 1024 px (WebP), and `idle.glb`, `walk.glb`, `run.glb`, `jump.glb`, `sit.glb`, `talk.glb` hold only the skeleton and one animation clip each. They load from this folder first. If a file is missing here, the game tries the GitHub CDN folder `https://cdn.jsdelivr.net/gh/stephdrealss/wild-city-assets@main/` (set `VITE_PLAYER_ASSETS_URL` to use another), then the built-in placeholder. NPCs always load from this folder.

The game loads four rigged humanoid models from this folder with `GLTFLoader`:

| File | Used for |
| --- | --- |
| `player.glb` | The player character (the face of the game) |
| `npc_female.glb` | Adult female NPCs (also elders) |
| `npc_male.glb` | Adult male NPCs (also elders) |
| `npc_child.glb` | Child NPCs |

The files that ship here are **placeholders** generated by `bun run models:generate`. They are simple rigged humanoids with seven hand-made animation clips. They are not photorealistic. For realistic people, drop your own `.glb` files over these names and reload. No code changes are needed. If a file is missing or broken, the game falls back to the built-in placeholder humanoid and logs a warning in the browser console.

## Swapping in your own models

1. Export a **rigged, skinned humanoid** as a binary glTF (`.glb`). Y-up, 1 unit = 1 metre, character **facing +Z**, standing with feet at y = 0 (any overall height works, the game rescales people to realistic heights).
2. Put the file in this folder using one of the names above (same names as the table).
3. Reload the game.

The player and every NPC are cloned from the file, so keep each model reasonably light (about 10k triangles or fewer is a good target for mobile).

### Separate animation files for the player

If your animations are separate files, put them next to `player.glb` (or in `public/models/animations/`):

`idle.glb`, `walk.glb`, `run.glb`, `jump.glb`, `sit.glb`, `talk.glb` (and optionally `drive.glb`)

The first clip in each file is used. The bone names must match `player.glb` (Mixamo exports from the same character do). Root motion is removed automatically so she stays in place while the game moves her. Any file you leave out falls back to the clip inside `player.glb`, then to Idle. A file whose bones do not match is ignored with a console warning.

### Animations (required for good results)

Put these clips in the file. The game finds clips by name, case-insensitive, matching any name that **contains** the word:

| Clip | Also accepted | Used when |
| --- | --- | --- |
| `Idle` | `stand`, `breath` | standing still |
| `Walk` | | slow movement, NPC routes |
| `Run` | `jog`, `sprint` | player moving at speed |
| `Jump` | | Space key or the jump button (plays once) |
| `Sit` | `seated` | resting on benches, NPCs on benches |
| `Talk` | `gesture`, `speak`, `wave` | talking to NPCs, chatting groups, vendors |
| `Drive` | `ride`, `sit` | riding a bike, keke or car |

A missing clip falls back to `Idle`. Mixamo animations work well: download each clip "without skin" or with the character, and bring them into one file (Blender: push each action to an NLA track, then export with "Animation" enabled). The Sit and Drive poses assume the hips drop to about 0.5 m above the floor.

### Optional names for outfits, hair and accessories

The game recolors materials and toggles meshes by name so the wardrobe, hairstyles and NPC outfits still work. Everything here is optional. Anything you do not provide is simply skipped.

- **Material names** (recolored): `skin`, `hair`, `top`, `bottom`, `shoes`, `accent`. NPC ankara prints are applied to the `top` material.
- **Mesh names** shown or hidden (a trailing `_1`, `_2` is ignored):
  - Hair: `Hair_bob`, `Hair_short`, `Hair_afro`, `Hair_wrap`, `Hair_puffs`, `Hair_braids`, `Hair_curls`. Leave all out for a bald model.
  - Clothing: `Skirt` (long garments), `Apron`, `Collar` and `Zipper` (the signature jacket), `Trim`.
  - Accessories: `Acc_chain`, `Acc_hat`, `Acc_backpack`.
  - The glasses and hoop earrings (`Glasses`, `Hoops`) are always visible.

For the player, keep the signature look in your model: warm brown skin, sleek black shoulder-length bob with a middle part, black cat-eye glasses, silver hoop earrings, and a hot pink zip-up track jacket.

## Performance and compression

The game limits how many people are fully animated at once (fewer on phones), animates mid-distance people at a lower rate, and swaps far-away people for a single cheap shape. You can still help:

- Compressed textures: the loader supports KTX2 (Basis) textures and meshopt-compressed meshes. The Basis transcoder is in `public/basis/`. Compress with [glTF-Transform](https://gltf-transform.dev):

  ```bash
  npx @gltf-transform/cli optimize player.glb player.glb --compress meshopt --texture-compress ktx2
  ```

- Keep textures at 1024 px or smaller, and use a single material per body part where you can.

## Regenerating the placeholders

```bash
bun run models:generate
```

This rewrites the four files above, so copy yours elsewhere first.
